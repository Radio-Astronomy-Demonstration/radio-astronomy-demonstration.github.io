This repository serves as the RAD (Radio Astronomy Demonstration) kit website. It uses [Jekyll](https://jekyllrb.com/) to generate the site from layout pages (found in [the _layouts folder](_layouts)). The website is hosted using [GitHub Pages](https://docs.github.com/en/pages/setting-up-a-github-pages-site-with-jekyll/about-github-pages-and-jekyll).

To run the website locally, clone this repository using `git`. Switch to the dev branch. Then follow the instructions on [Jekyll's website](https://jekyllrb.com/docs/installation/).
